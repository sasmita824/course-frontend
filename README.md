# Course Management System - Frontend

This repository contains the React frontend application for the **Full Stack Java Capstone App Deployment** (Week 6).

## Features
- **Student Authentication:** Secure login dashboard connected to Spring Boot backend.
- **Course Management:** Add, edit, delete, and view courses.
- **Real-time Filtering:** Search through courses by name or instructor.
- **Dashboard Metrics:** Overview card displaying total enrolled courses.

## Tech Stack
- **Frontend:** React, JavaScript, CSS3
- **Backend:** Spring Boot (REST API running on port 8082)
